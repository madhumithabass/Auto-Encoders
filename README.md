# Autoencoder – MNIST Image Reconstruction

## Project Overview

This project demonstrates the implementation of an **Autoencoder using Deep Learning** to reconstruct handwritten digit images from the MNIST dataset.

An Autoencoder is an unsupervised neural network that learns to compress input data into a smaller representation (encoding) and then reconstruct the original input from that compressed representation (decoding).

The model learns important features from images and attempts to reproduce the original images with minimal reconstruction loss.

## Objectives

- Understand the working principle of Autoencoders.
- Learn how neural networks perform dimensionality reduction.
- Compress image data into a lower-dimensional representation.
- Reconstruct images from encoded representations.
- Visualize and compare original and reconstructed images.

## Dataset

**MNIST Handwritten Digits Dataset**

- Contains 70,000 grayscale images.
- Image dimensions: 28 × 28 pixels.
- Pixel values range from 0 to 255.
- Contains handwritten digits from 0 to 9.
- Training images: 60,000.
- Testing images: 10,000.

## Project Workflow

1. **Data Loading:** Load the MNIST handwritten digit dataset.
2. **Data Preprocessing:** Normalize pixel values between 0 and 1.
3. **Reshaping:** Prepare image data for the Autoencoder model.
4. **Model Building:** Create the encoder and decoder architecture.
5. **Model Training:** Train the Autoencoder using the original images as both input and target output.
6. **Image Reconstruction:** Generate reconstructed images using the trained model.
7. **Visualization:** Compare original images with reconstructed images.
8. **Model Saving:** Save the trained model for future predictions.

## How Autoencoders Work

An Autoencoder consists of three main components:

### 1. Encoder
Compresses the original input image into a lower-dimensional representation.

### 2. Latent Space
Stores the compressed features learned by the network.

### 3. Decoder
Reconstructs the original image using the compressed representation.
